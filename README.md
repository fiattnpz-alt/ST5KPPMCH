# ระบบแบบประเมินความเครียด 3 หน้า (Stress Evaluation System)

ระบบประเมินความเครียดแบบง่าย จำนวน 3 หน้า ประกอบด้วย:
1. **หน้าลงทะเบียน (Registration)**: กรอกชื่อ นามสกุล ที่อยู่ และเบอร์โทรศัพท์
2. **หน้าทำแบบประเมิน (Evaluation)**: แบบประเมินระดับความเครียด ST-5 (5 ข้อคำถาม) ในสไตล์ Google Forms
3. **หน้าแสดงผลลัพธ์ (Result Dashboard)**: สรุปคะแนน ระดับความเครียด และคำแนะนำในการปฏิบัติตนตามผลลัพธ์ของแต่ละคน

---

## โครงสร้างของโปรเจกต์ (Project Structure)
```
แบบประเมินความเครียด (ด่วนมาก)/
├── index.html               # หน้าที่ 1: ลงทะเบียนผู้ใช้งาน
├── evaluate.html            # หน้าที่ 2: ทำแบบประเมินความเครียด (ST-5)
├── result.html              # หน้าที่ 3: แสดงผลคะแนนและคำแนะนำ
├── css/
│   └── style.css            # ไฟล์สไตล์ (Vanilla CSS) สะอาดและอ่านง่ายสำหรับทุกอุปกรณ์
├── js/
│   ├── config.js            # กำหนดค่าเชื่อมต่อ Google Sheets Web App URL
│   ├── register.js          # จัดการข้อมูลลงทะเบียนและบันทึกใน localStorage
│   ├── evaluate.js          # ประมวลผลแบบประเมินและส่งข้อมูลไปยังระบบจัดเก็บ
│   └── result.js            # แสดงผลลัพธ์และคำแนะนำรายบุคคล
├── google_apps_script.js    # โค้ดสำหรับคัดลอกไปวางใน Google Apps Script ใน Google Sheets
└── README.md                # คู่มือการใช้งานไฟล์นี้
```

## 🚀 วิธีการรันโปรเจกต์โลคอล (How to Run Locally)

เนื่องจากระบบนี้พัฒนาในรูปแบบ **Pure Static HTML/CSS/JS** คุณสามารถรันระบบนี้ได้ทันทีโดยไม่ต้องติดตั้ง Backend:

### วิธีที่ 1: เปิดโดยตรงบนเบราว์เซอร์
ดับเบิลคลิกที่ไฟล์ `index.html` บนเครื่องคอมพิวเตอร์ของคุณ ระบบจะเปิดและสามารถกดทำงานเปลี่ยนหน้าและคำนวณผลผ่าน `localStorage` ได้ทันที!

### วิธีที่ 2: รันผ่านโปรแกรมเซิร์ฟเวอร์จำลอง (แนะนำเพื่อทดสอบ API)
หากในเครื่องมี Node.js หรือ VS Code สามารถเปิดด้วย Live Server หรือรันคำสั่งเหล่านี้ใน Terminal:
```bash
# หากมี node ในเครื่องสามารถใช้คำสั่งนี้รันเซิร์ฟเวอร์ static ได้ทันที
npx serve .
```

## 📊 วิธีเชื่อมต่อกับ Google Sheets (Google Sheets Integration Setup)

เพื่อให้ข้อมูลทั้งหมดถูกจัดเก็บลง Google Sheets โดยตรง ให้ดำเนินการดังนี้:

1. **สร้าง Google Sheet ใหม่** หรือเปิดอันเดิมที่มีอยู่
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. ลบโค้ดเริ่มต้นทั้งหมดในไฟล์ `Code.gs` และคัดลอกโค้ดจากไฟล์ [google_apps_script.js](google_apps_script.js) ไปวาง
4. กดปุ่ม **บันทึก (Save)** (รูปแผ่นดิสก์)
5. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้ใหม่ (New deployment)**
6. เลือกประเภทเป็น **เว็บแอป (Web app)** (หากไม่มีให้กดรูปฟันเฟืองเพื่อเลือก)
7. ตั้งค่าการกำหนดค่าดังนี้:
   - **คำอธิบาย (Description):** เขียนอะไรก็ได้ เช่น `Stress Form Web App`
   - **เรียกใช้ในฐานะ (Execute as):** เลือก **ฉัน (อีเมลของคุณ)**
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** เลือก **ทุกคน (Anyone)**
8. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)**
9. อนุญาตสิทธิ์การเข้าถึง (ให้คลิก **ขั้นสูง / Advanced** -> **ไปยังเว็บแอป / Go to Web App (unsafe)** เพื่อยืนยันสิทธิ์เข้าถึงชีต)
10. คัดลอก **URL เว็บแอป (Web app URL)** (ที่ลงท้ายด้วย `/exec`) ที่ปรากฏหลัง Deploy สำเร็จ
11. เปิดไฟล์ [js/config.js](js/config.js) ในโปรเจกต์นี้และนำ URL ไปวางในช่อง `GOOGLE_SCRIPT_URL`:
    ```javascript
    const CONFIG = {
      GOOGLE_SCRIPT_URL: "วาง URL เว็บแอปของคุณตรงนี้"
    };
    ```

## 🌐 การนำขึ้นเวอร์ชันจริงบน Vercel / GitHub

คุณสามารถอัปโหลดโฟลเดอร์โปรเจกต์นี้ขึ้น GitHub และนำไปเชื่อมต่อกับ Vercel ได้ทันที:

1. นำไฟล์ในโฟลเดอร์นี้อัปโหลดขึ้น **GitHub Repository**
2. ไปที่ [Vercel.com](https://vercel.com) และเข้าสู่ระบบ
3. กด **Add New** -> **Project** และเลือก Repository ของคุณ
4. สำหรับโปรเจกต์ Static HTML Vercel จะตั้งค่าให้อัตโนมัติ (เลือก framework เป็น `Other` และกด `Deploy`)
5. ระบบจะพร้อมออนไลน์ให้ใช้งานและแชร์ลิงก์ได้ทันที!
